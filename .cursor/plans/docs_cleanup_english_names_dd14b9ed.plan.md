# تنظيف docs — أسماء إنجليزية ومحتوى عربي مفيد فقط

## القراران الثابتان

1. **نص التسجيل ≠ رن بوك اللجنة — يبقيان ملفّين.**  
   - [`docs/نص-التسجيل.md`](docs/نص-التسجيل.md) = جملة اللصق + جدول الحالات الأربع + ممنوع الادعاءات (لنموذج سيف والعرض الشفهي).  
   - [`docs/runbook-لجنة.md`](docs/runbook-لجنة.md) = سكربت 3 دقائق + أسئلة متوقعة + `npm test` (يوم اللجنة أمام الشاشة).  
   الفرق موجود؛ لا دمج ولا حذف. يُوضَّح في [`docs/README.md`](docs/README.md) سطران: متى تستخدم أي ملف.

2. **مساركم الوحيد في دليل سيف:** **الأمن السيبراني والتقنيات الدفاعية.**  
   CAUSASEAL = قرار قبل أثر أداة الوكيل + بصمة سبب بعد تغيّر الصياغة؛ هذا دفاع سيبراني لوكلاء، لا EdTech ولا بقية المسارات الـ13.

محتوى الملفات يبقى **عربيًا**. أسماء الملفات فقط إنجليزية.

## اختصار `saif.md` — ماذا يبقى / ماذا يُحذف

الملف الحالي (~684 سطر) خليط تقرير EdTech + دليل مشارك كامل + 14 مسارًا + 4 فئات عمر + روابط أخبار وجيميل. يصبح **دليل الفريق المختصر** فقط.

**يبقى (عربي، مرتب كتاسكات حيث ينطبق):**

- جملة هوية سيف + تواريخ الجدول التشغيلي (فتح التسجيل / إغلاق / معرض).
- أهلية الفريق كتاسكات مكتملة:  
  - [x] ثلاثة أعضاء · [x] أكبر من 18 · [x] مسجّلون على المنصة · [x] مسار سيبراني دفاعي.
- **ضوابط الملكية الفكرية والنزاهة** (كاملة — مهمة).
- وصف **مسار الأمن السيبراني والتقنيات الدفاعية فقط** + سطر يربط CAUSASEAL بهذا المسار.
- متطلبات المرفقات (فيديو / ملصق / نموذج / Drive) — ما زالت للتسليم.
- معايير التحكيم الأولي (جدول النسب) إن بقيت مفيدة قبل الحضور.
- **معايير الحضور لفئة أكبر من 18 فقط** (25/25/20/15/10/5) + أسئلة «ماذا نبحث عنه؟» الستة.
- من يقيّم يوم المعرض (أوزان اللجان).
- ميثاق مختصر + بريد `saif@tuwaiq.edu.sa` + رابط `https://saifair.sa/`.

**يُحذف بالكامل:**

- قسم EdTech / وزارة التعليم / استعلامات البحث.
- المسارات الـ13 الأخرى.
- فئات 11 / 12–14 / 15–18.
- شرح «كيف تنشئ حسابًا» و«سجّل في تويتر / طويق / تيليجرام» بعد ما التسجيل تم.
- فهرس Works Cited وروابط الأخبار وجيميل واستعادة كلمة المرور.
- الخاتمة التسويقية الطويلة والجوائز الزائدة (اختصار لسطر واحد إن لزم، أو حذف).
- أي لغة «دولية / مدارس / ستة أعضاء كشرط مفتوح» — تُستبدل بتاسك مكتمل للفريق الحالي.
