# docs — فهرس وثائق CAUSASEAL

محتوى الملفات **عربي** حيث يلزم العرض أو اللجنة. **أسماء الملفات إنجليزية** لترتيب الريبو العام.

| الملف | متى تستخدمه |
| --- | --- |
| [`registration-copy.md`](registration-copy.md) | لصق جملة المنتج وجدول الحالات الأربع في نموذج سيف أو العرض الشفهي. **ليس** سكربت تشغيل الشاشة. |
| [`judge-runbook.md`](judge-runbook.md) | يوم اللجنة أمام الديمو: دقائق العرض، الأزرار، أجوبة متوقعة، `npm test`. |
| [`idea-to-code.md`](idea-to-code.md) | ماذا بُني من الفكرة الأساسية، وما أُضيف فوقها، وتقدير سيف الداخلي (فئة أكبر من 18). |
| [`idea-causaseal-sermg.md`](idea-causaseal-sermg.md) | وثيقة الفكرة الأصلية للعرض — لا تُرفع أرقامها غير المقاسة كلغة إثبات. |
| [`saif.md`](saif.md) | مختصر سيف لفريقنا: مسار سيبراني دفاعي، أهلية مكتملة، ملكية فكرية، تواريخ، مرفقات، معايير أكبر من 18. |
| [`DESIGN_SYSTEM_AUDIT.md`](DESIGN_SYSTEM_AUDIT.md) | تدقيق هوية Soft / shadcn للمطوّرين. |

**الفرق باختصار:**  
`registration-copy` = **ماذا نقول** في النموذج.  
`judge-runbook` = **ماذا نضغط ونقول** أمام اللجنة على الشاشة.
