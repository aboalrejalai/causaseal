# Runbook لجنة سيف — CAUSASEAL (≈3 دقائق)

مصدر القفل: `docs/مطابقة-الفكرة-مع-الكود.md` · نص التسجيل: [`docs/نص-التسجيل.md`](نص-التسجيل.md).

## قبل العرض

1. `npm start` (أو `npm run dev`) — API + الواجهة شغّالان.
2. افتح الموقع على الجهة `demo`.
3. لا تعد Entra ولا EHR حقيقيًا — الشارات في `/architecture` كافية.

## السكربت (3 دقائق)

| الوقت | ماذا | ماذا تقول |
| ---: | --- | --- |
| 0:00–0:40 | `/architecture` | «نركب بين الوكيل والأثر. الموجود: القرار والموصّلات. المحاكاة: EHR/بريد. لاحقًا: IAM وSIEM.» |
| 0:40–1:30 | زر **شغّل مقارنة الهارنس** | صف **صياغة متغيرة**: هارنس ALLOW · بصمة INTERVENE · لا أصل · عمود **القطع** يسمّي الثابت. «هذا الفرق.» |
| 1:30–1:55 | صف lookalike | «ما نمنع المشروع على اللفظ وحده.» |
| 1:55–2:20 | صف **بداية جزئية** | «الهارنس يسمح؛ البصمة تراقب (VERIFY)؛ لا إرسال.» |
| 2:20–2:40 | `/connectors/mcp` أو HTTP | «الوكيل ينادي عبر MCP أو HTTP قبل الأداة — بلا مفتاح في النموذج.» |
| 2:40–3:00 | `/monitor` | «SOC العرض = أحداث هذه الجلسة. الأصل ما وصل للنظام المحاكى.» |

اختياري إن بقي وقت: زر **السيناريو الصحي المحاكى** على `/architecture`.

## أسئلة متوقعة (جواب سطرين)

| السؤال | الجواب |
| --- | --- |
| وين Entra؟ | في شريحة الهدف (لاحقًا). الديمو يثبت القرار قبل الأثر على MCP/HTTP و`orgId`. |
| وين EHR الحقيقي؟ | محاكاة معلّمة صراحة — صندوق صادر محلي باسم «نظام السجلات الصحية (محاكاة)». |
| ليش مو هارنس فقط؟ | الهارنس يوقف أداة معروفة الآن. البصمة توقف صياغة تغيّر شكلها والثوابت نفسها — صف mutated مع قطع مسمّى. |
| وش القطع؟ | اسم العلاقة الخطرة التي قُطعت (مثل تعليمة في النص المسترجع)؛ المهمة تكمل بنسخة محذوفة. |
| نسبة 90٪؟ | غير مقاسة؛ معلّمة في وثيقة الفكرة. النص المرفوع: `docs/نص-التسجيل.md` فقط. |
| جاهزين إنتاج؟ | نموذج أولي لسيف: قرار + موصّلات + إثبات يعاد بأربع حالات. مو بوابة مؤسسية كاملة. |
