# تقرير مطابقة الفكرة مع الكود

**نسبة الإنجاز من الفكرة المعروضة: 92 من 100**

**قاعدة البيانات السحابية:** غير مستخدمة. لا Supabase ولا Postgres. البصمات وأحداث الجلسة تُحفظ في ملف `data/causaseal-state.json` ويُعاد تحميلها بعد إعادة تشغيل الخادم. البذور ترجع إذا فُقد الملف.

**معنى النسبة:** الحلقة السببية على الويب مكتملة + تهيئة Capacitor (API base، android/ios/electron، `cap:sync`). الـ **8٪ المتبقية** = بناء واختبار وتوزيع التطبيقات على المنصات الخمس **بإذن صريح فقط**. ممنوع أي إصدار قبل موافقتك بعد انتهاء التعديلات.

**المشروع:** CAUSASEAL + SERMG™  
**الواجهة:** React + shadcn تحت `app/(dashboard)` و`components/causaseal`. الخادم `server.js` يخدم التصدير الثابت و`/api/*`.

**التوسع عبر المنصات (Capacitor):** مهيأ محليًا. `webDir=out`، `NEXT_PUBLIC_API_BASE` للتطبيق المغلف، سكربتات `cap:sync` و`cap:open:*` فقط — **لا** سكربتات release/apk/exe في الجذر.

**بوابة الإصدار:** ممنوع إصدار أي نسخة (ويندوز / ماك / لينكس / أندرويد / iOS) أو رفع متاجر حتى موافقة صريحة بعد انتهاء التعديلات.

## ما يعمل الآن

- [x] اختزال X-CFS يحذف سطور السجل غير الحرجة ويحسب نسبة التقليص
- [x] مطابقة Jaccard على الثوابت السببية، مع درجة تشابه لبنية الرسم
- [x] البصمة تحمل بيئة: تطوير، مؤسسة، أو سحابة
- [x] اكتشاف عبر السياقات: سبب تُعلّم في بيئة يُمنع في بيئة أخرى
- [x] SERMG يولّد طفرة مستجدة، يحفظ لقاحًا، ثم يمنع الإعادة من الذاكرة
- [x] بوابة التحليل تقرر ALLOW / VERIFY / INTERVENE
- [x] `POST /api/gateway/intercept` يعترض استدعاء الأداة قبل التنفيذ
- [x] محاكي وكيل في المراقبة: تسريب أو مسار مشروع
- [x] المراقبة ومركز العمليات والتقارير من أحداث الجلسة
- [x] التقارير تعرض متوسط الاختزال والبيئات التي اكتسبت المناعة، بوسم «أرقام هذه الجلسة»
- [x] الامتثال يُحدَّث من دليل الجلسة (NCA / OWASP)
- [x] زر عرض SAIF: منع، تعرّف، ثم سماح
- [x] صفحة الفريق
- [x] `NEXT_PUBLIC_API_BASE` + `apiUrl` للطلبات من WebView
- [x] Capacitor مهيأ على `out/` (android · ios · electron community)
- [x] سكربتات `cap:sync` / `cap:open:*` بدون أدوات توزيع
